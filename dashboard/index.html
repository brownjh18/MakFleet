System Limitations

📡 GPS Accuracy Dependency

System performance degrades with GPS errors >50m. Urban canyon effects near tall buildings may reduce accuracy.

⚡ Computational Complexity

ST-GNN inference requires ~45ms on modern hardware. Real-time processing supports up to 100 concurrent vehicles.

📊 Training Data Scarcity

Limited real bodaboda trajectory data available. Model trained primarily on Makerere University campus context.

🔋 Device Constraints

Continuous GPS processing affects device battery life. Requires stable internet for cloud-based inference.
